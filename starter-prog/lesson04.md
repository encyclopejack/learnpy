## This lesson is just a *guide to modules in Python*.

So, try type this inside a interpreter:

***import time***

***print(time.asctime())***

This should print the current time.

What happened?

So first we imported the *time* module, so it
gives you extra **functions** to do with.

You import a module by **import *modulename*** and use a function in a module
 by ***modulename.function()***.

Here are a table of modules:

name    | classic functions | lowest supported version

time    |   asctime, sleep  |      2.7

string  |  asciiletters     |      2.~

math    |  sqrt, pow        |      2.~
